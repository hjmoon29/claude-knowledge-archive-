IoT 통합테스트의 주관부서는 **IoT기획팀**(담당 표기 예: 문효준(정) / 최린아(부)).

**Why:** 사용자 지적(2026-11-24) — 통합테스트는 모든 제품 대응 업무에서 본래 IoT기획팀 주관. 말련향 주관부서 문서에서 IoT플랫폼개발팀으로 썼다가 수정함.
**How to apply:** R&R·일정·주관부서 문서에서 통합테스트 행은 IoT기획팀으로 기재. 단위테스트는 각 개발팀, 서비스 QA는 ITQA팀. 관련 [[project_malaysia_rnr_doc]]
