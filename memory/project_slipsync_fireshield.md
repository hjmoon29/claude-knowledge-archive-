## 1. 스마트 매트리스 슬립싱크 (Smart Mattress SlipSync)

### 개념
기존 스마트 매트리스(S8+ 등)에 수면 센서(슬립 센서) 액세서리가 연결된 버전.  
슬립 센서 제조사: **LEGACT(레갓)** 또는 **이원오엠에스(IOM)** 두 종류.

### 앱 화면 구성
- `DE>스마트 매트리스 슬립 싱크>홈` — 제품 홈 화면
- `DE>스마트 매트리스 슬립 싱크>제품관리` — 제품 관리
- `DE>스마트 매트리스 슬립싱크_제품관리` — 제품 관리 (별도 표기)

### 핵심 정책
- **센서 등록 완료 시**: 슬립싱크 전용 화면 노출
- **센서 미등록 시**: 기존 스마트 매트리스와 동일 화면
- **센서 소유자 변경 시**: 기존 사용자는 센서 미등록 상태와 동일하게 처리

### 제품 등록
- `REG>BLE콤보>등록가이드/매트리스 센서` — BLE 콤보 방식 센서 등록
- `REG>WiFi only>등록가이드/일반매트리스센서>WiFi네트워크연결/iOS` — WiFi 방식 센서 등록
- `REG>공통>스마트 매트리스 수면 센서 연결` — 연결 플로우
- `REG>공통>연결완료_스마트 매트리스 수면 센서 연결` — 연결 완료 화면

### 리포트
- `RE>스마트 매트리스 S8+ 슬립센서(LEGACT)` — LEGACT 센서 전용 리포트
- `RE>스마트 매트리스 S8+ 슬립센서(이원오엠에스)` — 이원오엠에스 센서 전용 리포트
- `RE>스마트 매트리스>수면 분석`, `RE>스마트 매트리스>수면 분석_데이터없음`
- `RE>스마트 매트리스>수면 분석_민감정보 미동의`

## 2. 시그니처 파이어쉴드 슬립 싱크 (Signature FireShield SlipSync)

### 개념
파이어쉴드(방염/난연 소재) 프리미엄 매트리스. **IoT 제어 기능 없음**.  
앱 표기: `매트리스 ㅣ 시그니처 파이어쉴드 슬립 싱크`

### 핵심 특징
- **홈 제품제어 탭 미제공 (제어 기능 없음)**: 제품 홈에 제어 탭 자체가 없음
- 슬립 싱크(수면 센서) 데이터 확인 기능만 제공으로 추정
- WiFi Off 아이콘 → BLE Only 방식으로 추정

### 앱 화면 구성
- `DE>시그니처 파이어쉴드 슬립 싱크_홈` — 제품 홈 (제어 탭 없음)
- `DE>시그니처 파이어쉴드 슬립 싱크>홈 제품제어 탭 미제공 (제어 기능 없음)` — 제어 불가 안내
- `DE>시그니처 파이어쉴드 슬립 싱크>제품관리` — 제품 관리

### 리포트
- 별도 섹션 없음 (아직 미기획이거나 스마트 매트리스 리포트와 공통 처리 가능성)

## 3. 매트리스 제품군 분류 (2026-08 기준)
