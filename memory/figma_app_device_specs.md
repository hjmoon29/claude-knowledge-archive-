## 앱 지원 OS 최소 사양 (COM_APP 섹션)

### Android
- **최소 버전: AOS 9.0 이상 (API 레벨 28 이상)**
- 최소 버전 미만 디바이스 → 구글 플레이 스토어에서 앱 검색/노출 불가
- APK 강제 설치(사이드로딩)도 불가

### iOS
- **최소 버전: iOS 15 이상**
- 최소 버전 미만 디바이스 → 앱 스토어에서 앱 검색/노출 불가
- 강제 설치 경로(사이드로딩)도 불가

## 태블릿 PC 지원 여부
- **별도 태블릿 스펙 없음** → 스마트폰(세로형) UI 기준으로만 설계
- Android 9.0+ 또는 iOS 15+ 태블릿이라면 앱 설치 자체는 가능하나, UI는 스마트폰에 최적화
- Windows 태블릿(PC) → 지원 불가 (앱스토어 없음)
- 기획서 내 "COM_APP/AOS", "COM_APP/IOS" 섹션만 존재, 태블릿 전용 섹션 없음

## 리프레시 토큰 / 세션 정책

### 앱 실행 시 토큰 만료된 경우
- 스플래시 → 서비스 소개 페이지 → 로그인 완료 → 투데이 홈
- (서비스 소개 페이지는 비로그인 상태에서 앱 실행 시 항상 노출)

### 앱 사용 중 만료된 경우
- 로그인 페이지로 자동 이동 → 로그인 완료 → 투데이 홈

### 백그라운드 앱 재실행
- 백그라운드에서 앱이 종료된 경우 → 재실행 시 스플래시부터 시작
- 백그라운드에서 종료되지 않은 경우 → 사용 중이던 화면으로 복귀
