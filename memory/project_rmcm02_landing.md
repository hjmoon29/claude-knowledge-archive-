RMCM02(전월 매트리스/수면센서 월간리포트 발행, 26.11 반영) 알림 탭 시 이동 화면.

- **알림 탭 시 이동 화면 담당 = 앱개발팀 최한나님** (윤혜원님과 확인, 2026-11-13). FE(윤혜원님) 아님.
- 앱 동작(11/12 최한나님 답변 + 사용자 해석): 리포트 탭 **1뎁스**로 이동. 1뎁스에는 수면센서 리포트 배너(섹션)가 있고, 1뎁스를 열 때 그 배너의 일일/주간/월간 중 **'일일'**을 선택해 불러옴.
  - 스마트매트리스 리포트 데이터가 있으면 → 스마트매트리스 리포트 내용 표시 (앱이 알림 년월을 넘김)
  - 수면센서 데이터만 있으면 → 수면센서 리포트 내용만 배너로 표시
- 기획서 대비: 알림 정의서는 'RE>매트리스 해당 월 선택 상태'. Figma 03_Report_매트리스_v1.11 39871:25211 기준 센서 기본 '일간', 매트리스 최근 7일/30일(달력 월 없음), 센서 월간은 30일 롤링.
- 발송 대상: 슬립싱크 6종 소유자 1명 (Jira IOCARERENEW2023-2825), 집계 소스 = 수면센서 ODM 월간 (2999)

- 결론(사용자, 11/13): RMCM02는 스마트매트리스가 아닌 **수면센서 리포트 알림** → 탭 시 **수면분석 리포트 화면(2뎁스)으로 이동하도록 수정 개발 검토를 최한나님께 요청함** (답변 대기)

**How to apply:** 알림 랜딩 문의는 최한나님께. 정의서의 '해당 월 선택 상태'와 실제('일일') 차이는 기획 결정 필요. 관련: [[project_slipsync_app_design]]
