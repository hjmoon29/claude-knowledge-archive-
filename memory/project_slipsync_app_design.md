## 1. 공통 정책

### 계정 / 장소 / 타임존
- 장소 > 사용자 구조 유지 (기존과 동일)
- **매트리스**: 단말기 중심 리포트 (타 단말기 로그인 시 리포트 데이터 삭제)
- **센서**: 개인 계정 중심 리포트 (타 단말기 로그인 시 리포트 데이터 유지)
- **장소 이동 불가** (재등록 필요, 재등록 시 기존 장소에서 삭제)
- 타임존: 매트리스·센서 모두 장소 타임존 기준

### 데이터 삭제 조건 (수면 리포트 데이터)
삭제 대상: 장소 삭제 / 제품 삭제 / 매트리스 보유 회원 내보내기 / 장소 나갈 시 / **다른 사용자가 제품 등록 시** / 회원 탈퇴 / 제품 소유자 변경 / **민감정보 동의 철회 시**
- 삭제 케이스 → 서버 연결 끊음 (민감정보 수집 차단)
- 연결 여부 표시용 실시간 데이터(redis)는 제외
- 데이터 유지: 동일 사용자 재등록(A→B→A 복귀), 동일 사용자 제품 추가

### 민감정보 동의
- **제품 등록 시 동의값 없으면 동의 팝업 → 미동의 시 등록 불가**
- 동의 철회 시 관련 제품 모두 앱에서 삭제

### 다중 사용자 등록
- 스마트 매트리스: 다수 등록 가능 (더블사이즈 왼쪽/오른쪽 고려)
- **센서: 1인 1장소만 등록 가능** (2인 등록 시 기존 사용자 삭제)
- 카테고리: 스마트/일반 매트리스 모두 '매트리스' 카테고리

## 2. 제품 등록 (Pairing)

### 스마트 매트리스
- BLE: 전원 인가 시 매트리스 상시 BLE 활성화 / 센서는 30분간 BLE 활성화
- 등록 순서: **① 매트리스 등록 → ② 수면 센서 등록** (센서는 선택적 등록)
- **매트리스 등록 플로우**: 전원 ON → 제품 찾기(바코드/목록/주변검색) → 제품 선택 → QR코드 스캔 → 등록 완료 → 제품 홈
- **수면 센서 등록 플로우**: 매트리스 제품상세 진입 → 매핑된 센서 BLE 검색 → 연결 팝업 → 등록가이드에서 '연결하기' → **민감정보 동의** → WiFi 선택·비번 입력 → 완료 → 제품 홈
  - 민감정보 미동의 시: 등록가이드 화면 유지

### 일반 매트리스 (센서만 존재)
- BLE: 전원 인가 시 센서 30분간 BLE 활성화
- 등록 방식: 주변 제품 찾기(센서 검색) + 센서 바코드 점유인증
- **플로우**: 전원 ON → 제품 찾기(A.주변/B.바코드/C.목록) → 연결하기 → **민감정보 동의** → 센서 바코드 스캔(B 경로는 Pass) → WiFi 선택·비번 → 완료 → 제품 홈
  - 민감정보 미동의 시: 검색된 제품 목록 화면 유지
  - 주변 제품 찾기 시 일반 매트리스용 센서만 표시 (스마트 매트리스용 센서 미표시)

## 3. 투데이 (홈)

### 스마트 매트리스
기존과 동일: 최근 7일 사용 타입, 매트리스 닉네임(좌/우), 수면습관 오브제, 사용타입 모듈, 데이터 불러오기, 7일 리포트 보기, 제품 카드 목록

### 일반 매트리스
- 주간(최근 7일) 사용 타입
- 수면센서 제품 닉네임
- **수면 유형 5종**: 균형잡힌 해바라기 / 신비로운 달맞이꽃 / 새벽빛 나팔꽃 / 섬세한 미모사 / 강인한 고사리 (주간 수면유형)
- 수면 점수(0~100): 주간 수면점수
- 최신 수면데이터 불러오기, 주간 리포트 보기, 제품 카드 목록
- 민감정보 미동의 → 수면센서 리포트 확인 불가 (미동의 시 등록 자체 불가)

## 4. 디바이스

### 스마트 매트리스
- **제품 카드 연결상태**: 매트리스 BLE 연결 + 센서 WiFi 연결 (각각 표시)
- 제품 카드 정렬: BLE 모델(스마트매트리스+센서) > WiFi 모델(일반매트리스+센서) 순
- 탭 시: 매트리스 홈 이동 **AND 센서 연결끊김이면 센서 등록가이드 진행**
- 제품 제어: 수면데이터 삭제 순서 → 스마트 매트리스 수면데이터 삭제 → 수면센서 수면데이터 삭제
- 제품 관리: WiFi 네트워크(센서 WiFi SSID 표시), MCU 버전(HVER+FVER 조합, Wi-Fi 미지원)

### 일반 매트리스
- **제품 카드 연결상태**: 센서의 WiFi 연결 상태만 표시
- **오늘 수면 시간 표시**:
  - 데이터 있음: "h시간m분"
  - 데이터 없음: "mm월 dd일 수면 시간" (최대 1년 내 마지막 데이터 기준)
  - 기준: 09시 이전은 전전일~전일, 09시 이후는 전일~당일
  - 민감정보 미동의: 'No data' 표시
- **제품 제어 탭 없음** (일반 매트리스는 제어 기능 없음)
- 제품 관리: 동일 (MCU 버전 표시, WiFi 미지원)

## 5. 리포트

### 조회 기간 정책
| 구분 | 스마트 매트리스 | 일반 매트리스 |
|------|----------------|--------------|
| 매트리스 리포트 | 주간/월간 | 해당없음 |
| 수면센서 리포트 | 일간/주간/월간 | 일간/주간/월간 |
- 기본 표시: 매트리스 '최근 7일', 센서 '일간' (각각 독립 기간 설정)

### 리포트 데이터 집계 기준
- **전일 09시 ~ 당일 09시 = 하루치 데이터**, 당일 09시 업데이트
- 주간: 최근 7일 (예: 5/11 08시 조회 → 5/3 09시~5/10 09시)
- 월간: 최근 30일 (예: 5/11 08시 조회 → 4/11 09시~5/10 09시)
- 기간 선택: 최근 12개월 월별 조회 가능
- 데이터=0 → 포함 / 데이터 미전송 → 미포함 (평균 계산)

### 수면센서 리포트 항목 (일간/주간/월간 공통)
1. **수면 유형** (5종): 입면지연 + 총 깸 시간 + 총 수면시간 + 수면 시작 시간 조합으로 산출
   - 산출식: `수면 분석 APP 기획_수면 유형화안3_자문 내용 반영 수정_공유.xlsx` 별도 정의서 참고
2. 수면 유형 설명 / 3. 수면 유형별 맞춤 코칭 (별도 정의서)
4. 수면 유형별 매트리스 추천 (버튼 → 릴랙스 모드 화면)
5. **수면 점수** (0~100) + 취침/기상/총수면/입면잠복기 데이터
6. **수면 단계 차트** (깸/REM/얕은수면/깊은수면)
   - 평가 기준:
     - **안정적**: 깊은수면 ≥15% AND REM ≥20% AND 깸 <5%
     - **양호**: 3가지 중 1개 미충족
     - **자주 깸**: 3가지 중 2개 이상 미충족
   - '깸' 범위: REM/얕은수면/깊은수면 제외한 모든 상태값 포함
7. 평균 심박수(분당) + 전일/주/월 대비 비교
8. 평균 호흡수(분당) + 호흡장애 시간(일일)
9. 맞춤 가이드: 수면 코칭 + 매트리스 추천 기능

### 매트리스 리포트 (주간/월간만)
1. 일별 뒤척임 / 2. 시간대별 뒤척임 / 3. 침대에 머문 시간

### 데이터 초기화
- 매트리스: 수면데이터 삭제 요청 시
- 수면센서: 확인 필요 (미정)
- 앱: 수면데이터 삭제 요청 / 계정 변경 / 앱 삭제 시
