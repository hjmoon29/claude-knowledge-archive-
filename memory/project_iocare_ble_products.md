## 공통 원칙
- **폰이 제품 옆에 있어야만 제어 가능** (서버 경유 원격 제어 불가)
- BLE 연결 끊기면 제어 탭/기능 비활성화
- 데이터 동기화: 실시간 서버 아님 → BLE 연결 순간에만 동기화
- 타임존: 비데 Asia/Seoul 고정, 매트리스·모션베드 OS 기준

---

## 매트리스
- BLE 끊김 시 제품 제어 탭 전체 접근 불가
- **동시 제어 충돌**: 리모컨 또는 다른 멤버 폰이 제어 중이면 레이어 팝업 발생
- 수면 데이터: BLE 연결 시점에만 동기화 (비연결 중 사용 데이터는 연결 후 업로드)

## 비데
- **프로필 6슬롯**: 단말기(폰) 기준으로 독립 프로필 저장
- **착좌 인식**: 앉으면 해당 폰의 설정값(물압·온도 등) 자동으로 비데에 세팅
- A/B 단말기 번갈아 사용 시 각자 설정 독립 유지
- **6슬롯 초과** 시 가장 오래된 프로필 자동 삭제 → 7번째 멤버가 쓰면 1번째 프로필 삭제

## 모션베드
- **사용자1 / 사용자2** 수동 전환 기능 (버튼으로 선택)
- 사용 데이터(수면 등)를 사용자1·사용자2 각각 월별 교차 업로드
- BLE 끊기면 거의 모든 제어 비활성화
- BLE 끊긴 상태에서 취침 음원 재생 시 → 모션베드로 재생 기기 자동 변경

## WiFi vs BLE Only 비교

| 항목 | WiFi 제품 | BLE Only 제품 |
|------|-----------|---------------|
| 제어 조건 | 어디서든 앱으로 | 폰이 제품 옆에 있어야 |
| 장소 공유 효과 | 멤버 모두 원격 제어 가능 | 물리적 접근 시에만 제어 |
| 동시 사용 | 서버가 중재 | 충돌 팝업 발생 |
| 데이터 동기화 | 실시간 서버 연동 | BLE 연결 순간에만 동기화 |
| 사용자 구분 | 장소 멤버 권한 체계 | 비데: 6슬롯 프로필 / 모션베드: 사용자1·2 수동 선택 |

**Why:** 사용자가 전체 66개 Figma 파일에서 BLE Only 제품의 장소 공유 동작 정책 학습 요청
**How to apply:** BLE 제품 제어·공유·데이터 관련 질문 시 이 정책 기반으로 답변
