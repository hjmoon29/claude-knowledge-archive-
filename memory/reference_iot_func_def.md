사용자 팀(IoT기획팀)에서 **"IoT기능정의서"** 라고 부르면 Google Drive의 **CW_IoCare_제품_기능정의서** 를 가리킨다 (2026-11-09 사용자 지정).

- 최신(11/12 기준): `CW_IoCare_제품_기능정의서_v2.78_20261112` (v2.77 로봇청소기 최유나님 11/11 → v2.78 좌욕스파 비데 +1분 행 추가, 백업 폴더 1biNGeQdtdsaHpLgqQiDLiK3HJzg9pWMQ) — 구글 시트 ID `1w15PUJrj9uqBBfZQLJrbYqSmm66NPC8gpf3vyQS2nkU` (부모 폴더 1PtAKWop7WHi9P69_8NAzJfUo9QkP4QzQ)
- 버전이 자주 올라감(v2.72→2.73→2.75, 주 1~2회). 쓰기 전에 Drive에서 `name contains 'CW_IoCare_제품_기능정의서'` 최신 수정순으로 다시 찾을 것. `[FE팀 대응용]`·`[FE형식 …]`·`…백업…` 사본은 제외
- 혼동 주의: 상품기획팀이 쓰는 "제품 기능정의서"(Water상품 기능정의서 등, 향지별)와 다름. 상품화 착수서 '7) IoT 서비스 기획' 탭에도 "IoT 기능정의서" 제목이 있으나 이는 착수서 IoT 파트
- IoT업무봇 제품별 진행상황의 'IoT 기능정의서'(iot_def) 단계가 이 문서 기준

**How to apply:** 대화·문서 작성 시 "IoT기능정의서"로 지칭하고, 근거 인용 시 파일명·버전 병기. 관련: [[reference_consumable_source_docs]], [[project_work_bot]]
