사내 문서(QA 문의 답변 xlsx, wiki, 이메일 등) 및 사용자와의 대화에서 모두 **존댓말(-습니다/-드립니다)** 을 사용할 것. 사내 인물 언급 시 반드시 **"님"** 붙일 것 (예: "홍민재 님", "황혜련 님").

**Why:** 2026-09-14 QA 문의 답변 작성 시 "(cc. 홍민재 / 황혜련)"처럼 '님' 없이 이름만 표기해서 사용자가 "일단 존칭을 써라"고 정정. 사내 협업 문서는 타 부서에 형효준 이름으로 나가므로 예의 결여 시 실례가 됨. 사용자와의 캐주얼 톤(-야/-어)도 지양하고 존댓말 유지 요청 취지로 판단.

**How to apply:**
- 파일에 작성하는 답변 문구: 모든 인물 이름 뒤에 '님' 필수, 문장은 -습니다/-드립니다 종결형
- 사용자에게 보내는 채팅 응답: 반말(~야, ~어, ~볼래?) 사용 금지, 존댓말 유지
- 요약/보고 톤: "완료했습니다", "확인 부탁드립니다", "~하시겠습니까?" 형식
