## 핵심 정책 요약

### 장소 선택 (LOC 장소설정)
- **디바이스 기준**: 휴대폰별 마지막 선택 장소가 디폴트 (동일 계정 2대 폰이라도 각각 다른 장소 가능)
- **계정 기준 공통 노출**: 장소 이름, 위치, 제품 사용자 수, 멤버, 등록 제품
- **관리자 최소 장소**: 관리자 장소 최소 1개 필수. 마지막 1개 삭제 시 자동으로 신규 장소 생성
- **디폴트 장소 변경 조건**: 디폴트 장소 삭제/권한 삭제 시 → 다음 노출 순서 장소로 자동 선택
- **장소 생성 시 OS 국가/타임존 저장** (이후 수정 불가)
- **Tuya 플랫폼 제품(에어컨/청소기)**: 제품 등록 시점 OS 타임존 기준, 이후 변경 불가
- **BLE only 타임존**: 비데 Asia/Seoul 고정, 매트리스/모션베드 OS 기준
- **장소 목록 페이징**: 20개 단위, 최하단 스크롤 시 자동 호출
- **삭제된 장소 선택 시**: "삭제된 장소이거나 멤버가 아니에요." 토스트 → 마지막 등록 장소로 이동

### 장소 선택 진입 경로별 동작
- **TO/DE/RE/RO 헤더로 진입**: 장소 선택 시 바텀시트 닫히고 선택 장소로 변경
- **ME>장소설정btn 진입**: 장소 선택 불가 (탭 시 아무 동작 없음)

### 새로운 장소 추가 (b새로운장소추가)
- 장소 이름 중복 허용, 무한 생성 가능
- 이름 최대 18자 (띄어쓰기 포함)
- 생성 시 OS 설정 국가 정보로 저장
- 저장 후 토스트: "새로운 장소가 추가되었습니다."
- b장소위치설정>장소위치확인에서 "기본 위치로 설정" 체크 시 장소 이름+주소 함께 저장

### 장소 위치 설정 (b장소위치설정)
- 주소 검색 API: 구글 지도 API
- 현재 위치 버튼: 위치 권한 필요, 미허용 시 커스텀 팝업 호출
- iOS: OS 위치 서비스 OFF 시에도 동일 팝업 호출
- 검색 결과 최대 5개, 페이징 없음
- 검색어 포함 글자 별도 색상 표시

### 지도에서 위치 설정 (b지도위치선택)
- 구글 지도 API 사용
- 드래그로 위치 조정, 위치 아이콘으로 표시
- 설정 불가 위치(바다 등): "설정 가능한 위치가 아닙니다." 텍스트, 설정 btn 비활성

### 장소 이름 변경
- 최대 18자 (띄어쓰기 포함)
- 저장 후 토스트: "장소 이름이 변경되었습니다."

### 장소 관리 - 관리자 권한
- 관리자는 1명만 가능 (권한 이관/추가 미지원)
- 관리자 권한: 이름변경/위치설정/사용자수설정/멤버추가삭제/등록제품이동삭제/장소삭제
- 사용자 권한: 이름변경/위치설정/사용자수설정/멤버추가(상세 진입 불가)/등록제품이동삭제 / 장소삭제 불가
- 멤버 노출 순서: 관리자 > 본인계정 > 사용자(최근 등록 순)
- 제품 카테고리 오브제 icon 순서: 정수기>청정기>가습기/제습기>매트리스>비데>에어컨>청소기

### 이름/아이디 마스킹 정책
- 0자: '알수없음' 노출
- 1자: 전체 마스킹
- 2자: 첫번째만 노출, 2번째 마스킹
- 3~5자: 첫+마지막 노출, 가운데 마스킹
- 6~9자: 앞2+뒤2 노출
- 10~19자: 앞3+뒤3 노출
- 20자 이상: 앞5+뒤5 노출
- 이메일: @앞 4번째 자리부터 마스킹, @ 뒤 .앞 마스킹
- 전화번호 10자 미만: 앞2+뒤2, 10자 이상: 앞3+뒤4

### 장소 사용자 수 (b장소사용자수)
- 기본값: 4인, 최소 1인, 최대 50인
- 스텝퍼 ±1씩 조절, 핸들 드래그 가능
- 저장 후 토스트: "장소 사용자 수가 변경되었습니다."

### 멤버 초대 (b멤버초대)
- 링크 공유: URL 1개당 1계정만 초대 가능, 유효기간 24시간
- QR코드: 1개 QR로 다수 초대 가능, 유효기간 1시간
- QR 페이지 진입 시마다 신규 QR 발급
- Deeplink: 앱 미설치 → 마켓 → 앱 실행 → 로그인 → 장소 초대 레이어

### 초대 메시지 케이스
- 정상: "$관리자명$님이 $장소명$의 멤버로 초대했어요"
- 이미가입: "초대받은 링크로 이미 다른 멤버가 초대되었어요." (URL 재사용 불가)
- 유효기간만료: "초대받은 링크는 유효기간이 만료되었어요."
- 장소삭제: "초대받은 장소가 삭제되었어요."
- 이미참여중: "이미 참여중인 장소예요."

### 멤버 관리
- 멤버 노출 순서: 관리자 > 사용자(최근 등록 순)
- 계정 아이디 우선순위: 전화번호 > 아이디 > 해시(알수없음)
- 멤버 삭제: 관리자만 가능

### 제품 관리
- 제품 목록 정렬: 1순위 BLE only 제품, 2순위 네트워크 연결 제품, 각 순위 내 최신 등록 순
- 페이징: 20개 단위
- Tuya 플랫폼 제품(에어컨/청소기): 장소 이동 불가 (수동 삭제 후 재등록, 데이터 초기화)
- 등록 장소 1개일 때 이동 시도: "등록제품_a제품이동불가" 팝업 → 장소 추가 유도

### 장소 위치 확인
- 저장 후 토스트: "장소 위치가 저장되었습니다."
- 진입 경로에 따라 저장 후 이동 화면 다름:
  - 장소관리 진입: 저장 후 LOC>장소관리로 이동
  - 정수기 날씨 위치 컴포넌트 진입: 저장 후 DE>정수기홈으로 이동
