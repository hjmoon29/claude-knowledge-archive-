## 핵심 정책

### 점유인증 (WiFi 제품 등록 시)
- 제품 등록 시 물리적 버튼 누름(점유인증) 필요
- 목적: 해당 제품을 실제로 점유한 사람만 등록 가능하도록 차단

### 기등록 제품 재등록 차단
- 이미 등록된 제품을 다른 장소에 등록 시도 시 → `[제품등록불가_a기등록제품]` 팝업 발생
- **EM005**: 동일 제품을 동일 장소에 재등록 시도 → 차단
- 결론: 제품은 한 장소에만 존재 가능, 이동은 "장소이동" 기능을 통해서만

### Tuya 플랫폼 제품 (에어컨·로봇청소기)
- **장소 이동 불가**: 수동 삭제 후 다른 장소에 재등록해야 함
- 장소 이동 시 데이터 초기화 발생
- 등록 시점 OS 타임존 기준으로 고정, 이후 변경 불가

### 장소 이동 (일반 제품)
- 등록 장소가 1개뿐일 때 이동 시도 → `[등록제품_a제품이동불가]` 팝업 → 장소 추가 유도
- 장소 이동 완료 시 기존 장소에서 제품 사라짐

## 장소-제품 관계 핵심 원칙
- 제품은 항상 **1개 장소에만** 귀속
- 같은 장소 멤버는 해당 제품을 공유 (WiFi: 원격 제어, BLE: 근처에서만 제어)
- 철수(A) 장소에서 영희(B) 장소로 이동 = 철수 장소에서 제품 삭제 + 영희 장소에 추가

**Why:** 사용자가 제품등록 기획서를 통해 제품-장소 귀속 정책 학습 요청
**How to apply:** 제품등록·장소이동·재등록 관련 질문 시 이 정책 기반으로 답변
