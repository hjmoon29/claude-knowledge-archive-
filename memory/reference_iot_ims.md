**IoT IMS** = IoCare Integrated Management System (사내 어드민/관제 콘솔)

## URL
- **IoCare IMS (국내향):** https://ims.iot.coway.com/dashboard/siteMap
- **NECOA IMS (해외향):** ims.iot.coway.com 계열 + 일부 쇼피파이 병행

## 주요 기능
| 영역 | 상세 |
|---|---|
| 플랫폼 관리 > 프로젝트 관리 | 서비스 매니저 앱·제품 연동용 프로젝트 코드 등록. 미등록 시 검증/운영 반영 불가 (최초 등록은 IoT플랫폼개발팀) |
| 공지사항·시스템점검 | IoCare+/NECOA 앱 공지 등록 창구 (구 IoCare는 MCNC 박종관님 요청) |
| 다국어 세팅 | 화면 문구 다국어 등록 |
| 진단·소모품 | 진단 이미지, 소모품 정의 등록 (예: 노블 공청기 진단 이미지 5종 교체) |
| 검증/운영 반영 | 제품 프로토콜/기능 QA→운영 승격 |

## 담당 RnR (업무 RnR 페이지 id=392364961 원문 기준)
- **기획측 IMS 세팅:** IoT기획팀 — 화면설계서 작성 + IMS 세팅 + 다국어 (메가존 협업)
  - 정수기·식기세척기: 이주리·김민선
  - 청정기·가습기·제습기·보행보조·AI 루틴 고도화: 김민선·정명주
  - 에어컨·로봇청소기·매트리스·비데: 정명주·이주리
- **IMS 총괄 (개발측):** IoT플랫폼개발팀 (팀 단위만 명시, 개인 이름 없음)
- **IMS API 개발 / 사이트 화면설계·개발:** 오탁종, 정지현 (IoT플랫폼개발팀)
- ⚠️ "노창현·김호원·박상만"은 IMS 총괄이 아님 (프로토콜 설계자로 혼동한 오기 — 원문 재확인 필요)
