기획 문서(구글 시트 등) 내용을 고칠 때 **수정·추가된 글자는 파란색**, **삭제할 내용은 바로 지우지 말고 취소선**으로 남긴다 (2026-11-24, 좌욕스파 비데 앱 설계 방향 정의 검토 때 사용자 지시).

**Why:** 검토자가 무엇이 바뀌었는지 한눈에 보고, 삭제는 확인 후 확정하려는 목적.
**How to apply:** 셀 단위 textFormatRuns로 기존 서식은 유지하고 바뀐 부분만 파란색/취소선 적용. 신규 행은 전체 파란색. [[feedback-doc-version-backup]] 규칙(백업·버전·이력)과 함께 적용.
